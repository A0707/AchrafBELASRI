الأعمال

المشاريع والتنفيذ

مشاريع فعلية نُفّذت في بيئة الإنتاج، من النشر إلى التشغيل اليومي.

01البنية التحتية

المحاكاة الافتراضية الهجينة

إدارة وتحسين منصات المحاكاة الافتراضية. النتيجة: ترحيل حي دون انقطاع الخدمة.

  • إنشاء الأجهزة الافتراضية على VMware ESXi / vCenter و Nutanix AHV.
  • الشبكة الافتراضية: المبدلات الافتراضية، شبكات VLAN، التقسيم.
  • الترحيل الحي بين المضيفات دون توقف.
VMware · Nutanix AHV · Proxmox · VLAN
02التشغيل

المراقبة وإدارة الخدمات

مراقبة استباقية وإدارة منظمة للحوادث. النتيجة: كشف مبكر للأعطال وتتبع اتفاقيات الخدمة.

  • المراقبة عبر Zabbix: لوحات المتابعة، عتبات الإنذار، تتبع SLA.
  • الدعم من المستوى الثاني والثالث عبر GLPI وفق ITIL v4.
  • تشخيص الحوادث والتحسين المستمر.
Zabbix · GLPI · ITIL v4 · HAProxy
03الأمن

أمن المحيط Fortinet و SD-WAN

تأمين وربط بنية تحتية متعددة المواقع. النتيجة: روابط WAN مرنة وتحكم كامل في الوصول.

  • نشر وتحصين أجهزة FortiGate 400E / 200F / 100F.
  • التحكم في الوصول عبر FortiNAC (802.1X) و FortiAuthenticator و EMS.
  • Secure SD-WAN وأنفاق VPN IPSec / SSL وسياسات WAF.
FortiGate · FortiNAC · SD-WAN · VPN · WAF
04المرونة

النسخ الاحتياطي عبر Veeam

استراتيجية نسخ واستعادة على كامل البنية. النتيجة: استعادة مُختبَرة واستمرارية مضمونة.

  • مهام النسخ الاحتياطي والنسخ المتماثل بين المواقع.
  • سياسات الاحتفاظ وجدولة نوافذ النسخ.
  • المتابعة واختبارات الاستعادة الدورية.
Veeam · النسخ المتماثل · الاستعادة
05الأنظمة

Active Directory والحوكمة

أساس الدليل والأمن لبيئة Windows Server. النتيجة: إدارة مركزية للوصول وسياسات موحدة.

  • تنصيب الخوادم (AD، ADC، DNS، DHCP، WSUS، IIS، FTP).
  • حسابات المستخدمين، صلاحيات NTFS، سياسات المجموعة (GPO).
  • سياسات الأمن والتحصين.
Windows Server · AD · GPO · NTFS
06السحابة

Microsoft 365 والهوية

البريد والتعاون وتأمين الوصول السحابي. النتيجة: وصول محمي بالتحقق متعدد العوامل.

  • Exchange Online: صناديق البريد، التراخيص، SharePoint.
  • أمن الوصول: MFA والوصول المشروط عبر Microsoft Entra ID / Azure AD.
  • إدارة التراخيص والامتثال.
M365 · Exchange · Microsoft Entra ID · MFA
