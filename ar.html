أمن المحيط Fortinet و SD-WAN

تأمين وربط بنية تحتية متعددة المواقع.

النتيجة

عرض التدخلات+

تدخلاتي

  3. Secure SD-WAN وأنفاق VPN IPSec / SSL وسياسات WAF.

البيئة التقنية

FortiGate · FortiNAC · SD-WAN · VPN · WAF

مشاريع أخرى

01البنية التحتية

المحاكاة الافتراضية الهجينة

إدارة وتحسين منصات المحاكاة الافتراضية. النتيجة: ترحيل حي دون انقطاع الخدمة.

  • إنشاء الأجهزة الافتراضية على VMware ESXi / vCenter و Nutanix AHV.
  • الشبكة الافتراضية: المبدلات الافتراضية، شبكات VLAN، التقسيم.
  • الترحيل الحي بين المضيفات دون توقف.
VMware · Nutanix AHV · Proxmox · VLAN
05الأنظمة

Active Directory والحوكمة

أساس الدليل والأمن لبيئة Windows Server. النتيجة: إدارة مركزية للوصول وسياسات موحدة.

  • تنصيب الخوادم (AD، ADC، DNS، DHCP، WSUS، IIS، FTP).
  • حسابات المستخدمين، صلاحيات NTFS، سياسات المجموعة (GPO).
  • سياسات الأمن والتحصين.
Windows Server · AD · GPO · NTFS
06السحابة

Microsoft 365 والهوية

البريد والتعاون وتأمين الوصول السحابي. النتيجة: وصول محمي بالتحقق متعدد العوامل.

  • Exchange Online: صناديق البريد، التراخيص، SharePoint.
  • أمن الوصول: MFA والوصول المشروط عبر Azure AD.
  • إدارة التراخيص والامتثال.
M365 · Exchange · Azure AD · MFA
